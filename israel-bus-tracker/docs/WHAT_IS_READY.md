# מה מוכן ומה עדיין לא (שלב 4)

קצר ובכנות. "נבדק" = בדיקה אוטומטית על הלוגיקה. **שום דבר לא נבדק על מכשיר.**

## מה אפשר לעשות עכשיו

- **להריץ את הלוגיקה של האפליקציה בבדיקות:** NFC (מכונת מצבים, ללא APDU בלי מפרט), תשלום (Mock/NotImplemented, חסימת offline, הגנת נתוני כרטיס), פרופיל, מועדפים, היסטוריה, מתכנן מסלול (ולידציה/שגיאות), דירוג תחנות קרובות, פורמט זמני הגעה, פתרון כתובות שרת. 169 בדיקות, כולן עוברות.
- **להריץ את ה-backend במצב הדגמה** (`DEMO_MODE=true`) ולקבל קווים, תחנות, הגעות ורכבים *מדומים* בתל אביב. (22 בדיקות backend עוברות; 4 קבצי בדיקה דורשים התקנת תלויות.)
- **לבנות את האפליקציה אצלך** (`npm install` ואז `typecheck`, `test`, `expo run:android`). הקוד נקרא ונפרס תקין (parse) בכל הקבצים, אבל לא עבר typecheck/Metro אמיתיים בסביבה הזו.
- **להשתמש בכל המסכים**: תכנון מסלול (UI + איתור יעד), תשלום, רב-קו, אזור אישי (מועדפים, היסטוריה, הגדרות, התראות, פרטיות, עזרה), שירותי תחבורה, מפה.

## מה דורש שירות חיצוני / API / מכשיר

| דרוש | בשביל מה |
| --- | --- |
| פיד GTFS-RT או SIRI-SM (מפתח + IP לבן ממשרד התחבורה) | נתוני אוטובוסים אמיתיים במקום הדמו |
| שרת ה-backend על כתובת **https** + `EXPO_PUBLIC_API_URL` | כל נתוני הרשת באפליקציה. ב-release בלי כתובת https תקינה האפליקציה לא פונה לשום מקום (מוצג מצב שגיאה/ריק) |
| מפתח Google Maps (Android/iOS) | המפה. בלי מפתח: "המפה אינה זמינה" |
| מכשיר Android עם NFC | לאמת זיהוי כרטיס ו-UID. לא נבדק מעולם על חומרה |
| **מפרט רב-קו מאומת** (AID/פקודות קריאה, מקור ותאריך) | יתרה / פרופיל / היסטוריית כרטיס. עד אז: NOT_IMPLEMENTED |
| ספק סליקה (SDK + שרת) | תשלום ואמצעי תשלום. עד אז: NOT_IMPLEMENTED |
| מנוע תכנון מסלול (OTP או אחר) | מסלולים. עד אז: NOT_IMPLEMENTED |
| שרת חשבונות + שירות התראות | התחברות, סנכרון, התראות |
| Android SDK + רשת | `expo export` / `prebuild` / `run:android` |

## מה לא נבדק בכלל

מראה בפועל (Egg UI, RTL, SafeArea, מקלדת, הנפשות, bottom sheet), GPS, מפה, NFC בחומרה, WebSocket מול שרת חי, נגישות עם קורא מסך, ביצועים ב-runtime (נבדקו בקריאת קוד בלבד).

## לפני שמפיצים

החלף `il.example.bustracker` (package / bundleId) ו-`eas.projectId`; הגדר חתימה אמיתית (ה-CI חותם release ב-debug keystore: לבדיקות פנימיות בלבד); הגבל את מפתח Google Maps לפי package + SHA-1; הגדר `CORS_ORIGIN` מפורש ב-backend.
